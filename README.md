# Fábrica de Quadrinhos

A comic strip builder for kids (Portuguese UI): pick a panel layout, add backgrounds, characters and speech balloons, then save the comic as an image.

Run: open `index.html` in a browser, or `python3 -m http.server 5179` in this folder and open http://localhost:5179

- **Cenário**: backgrounds for each panel
- **Figuras**: characters and stickers you can resize, flip, rotate, layer, copy and delete
- **Balões**: speech, thought, shout and narration balloons with a movable tail
- **Salvar imagem**: exports the comic as a PNG (via html2canvas)

Everything lives in a single `index.html`.
